# 05 · 数据格式

三种核心产物格式，从原始到标准化逐层清洗。

## 5.1 raw/<slug>/asr_raw.txt（ASR 原文，带时间戳）

每行一句，格式：

```
[HH:MM:SS,mmm] Speaker N: text
```

示例（取自 E31）：
```
[00:00:10,480] Speaker 0: 大家好，欢迎收听探极生物生存指南，我是爱读文献的梦妮。
[00:00:15,198] Speaker 0: 本期节目是由巴斯夫发起的选择可持续的职场路企划系列之一。
```

- 时间戳：`[时:分:秒,毫秒]`，毫秒 3 位逗号分隔。
- 说话人标签：`Speaker 0` / `Speaker 1` …（Stepfun 单说话人默认 `Speaker 0`）。
- 含中英混杂原文（未做语言清洗），如 `Every October, a hole appears...` 直接拼接。
- 由 `merge.py` 合并各 `chunk_NNN.txt` 产出（chunk 的 txt 同样格式）。

## 5.2 raw/<slug>/asr_raw.srt（ASR 字幕版，标准 SRT）

序号 + 时间轴 + 文本 + 空行：

```
1
00:00:10,480 --> 00:00:14,720
大家好，欢迎收听探极生物生存指南，我是爱读文献的梦妮。

2
00:00:15,198 --> 00:00:20,320
本期节目是由巴斯夫发起的选择可持续的职场路企划系列之一。
```

- 时间轴 `HH:MM:SS,mmm --> HH:MM:SS,mmm`，**无说话人标签**（纯字幕）。
- 由 `merge.py` 合并各 `chunk_NNN.srt` 产出，时间戳已按 chunk 偏移并重新编号。

## 5.3 cleaned/<slug>.md（标准化转录稿，对外交付物）

**标准（2026-06-24 用户定）**：无错字、无时间戳、段落呈现、无小标题、Speaker 替换为真实身份。

特征：
- 无 `[00:00:10,480]` 类时间戳。
- 无 H1/H2/H3/小节标题，纯净一段一段流。
- 合并相邻同说话人内容，按"说话人名：内容"分段（如 `梦妮：…`、`朱雪怡：…`）。
- Stepfun 单说话人 `Speaker 0` 按实际身份替换（梦妮 / 朱雪怡 / 嘉宾名）。

示例（取自朱雪怡短视频，顶层 cleaned 版，单段流）：
```
发现我还挺擅长观察别人的，这个擅长是技术上的擅长。观察着观察着，我会发现观测这个事情是可以选用不同的尺度的，就好像电影镜头文学语言……
```

对比（`raw/.../cleaned/` 内的**中间稿**，违反标准，仅供参考）：
```
## 精修说明
[00:00:00,000] 朱雪怡：发现我还挺擅长观察别人的……
```
> ⚠️ 仅顶层 `cleaned/<slug>.md` 是合规交付物；`raw/` 内嵌的 `cleaned/` 是带时间戳+H2 的半标准化中间产物。

## 5.4 chunk 文件（中间产物）

`raw/<slug>/chunks/chunk_NNN.{mp3,srt,txt}` 三件套：
- `chunk_NNN.mp3`：ffmpeg 切出的 3 分钟 16k 单声道 64k 片段。
- `chunk_NNN.srt` / `.txt`：该片段的 Stepfun 识别结果（格式同 §5.1 / §5.2 单块）。
