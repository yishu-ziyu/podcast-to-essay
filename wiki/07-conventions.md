# 07 · 约定与规范

## 7.1 转录稿标准（2026-06-24 用户定）

`cleaned/<slug>.md` 必须满足：

| 规则 | 说明 |
|------|------|
| **无错字** | 仅 100% 上下文确证才改错字，否则保留 ASR 原貌 |
| **无时间戳** | 删除所有 `[00:00:10,480]` 类时间戳 |
| **段落呈现** | 合并时间戳相邻的同说话人内容，按"说话人名：内容"分段 |
| **无小标题** | 不写 H1/H2/H3/小节，纯净一段一段流 |
| **Speaker 标签** | Stepfun 单说话人输出 `Speaker 0` → 按真实身份替换（梦妮 / 朱雪怡 / 嘉宾名） |

**范围边界**：只做清晰干净的转录稿；写稿（rewrite / published）不归本项目，步骤已于 2026-06-24 删除。

## 7.2 INDEX.md（期次登记表）

- 定位：**只登记转录状态**，不登记写作状态。
- 列：`slug | 标题 | 时长 | raw | cleaned | 备注`。
- 每完成一期，在对应行把 `raw` / `cleaned` 标 ✓，并补标题、时长、备注（如 ASR 引擎、段数、标准化方式）。
- ⚠️ 备注中的"段数"需明确口径（音频切块数 vs ASR 句段数），当前 e31 写"604 段"与磁盘 28 个 chunk 不一致（见 [02 章 §2.4](02-directory-structure.md)）。

## 7.3 STYLE_NOTES.md（风格学习笔记）

- 原则：只记"**你点过的**风格特征"，**不展开成规则**（"写稿是用户自己的事，AI 不抽象风格"）。
- 表 `已点过的风格来源`：列 `来源 | 类型 | 核心特征`（已记：梦妮/朱雪怡/阮一峰；奕枢待补）。
- 沉淀规则：点哪个来源加一行；把特征抽象成写作规则 → **不做**。

## 7.4 目录与命名约定

- 每期：`raw/<slug>/`（ASR 原始）+ `cleaned/<slug>.md`（标准化）。
- slug：`YYYY-MM-DD-节目名-主题`（小写连字符）。
- `raw/<slug>/` 内：`source.<mp3|wav>`、`chunks/`（切块，可选保留）、`asr_raw.txt` / `asr_raw.srt`、可选的 `asr_raw/`（当前为空）。
- 对外唯一交付物：`cleaned/<slug>.md`。

## 7.5 质量自检

cleanup 完成后，可用引擎 `verify.sh` 校验最终稿是否残留坏模式：
```bash
bash ~/.claude/skills/asr-transcript-refinement/scripts/verify.sh cleaned/<slug>.md
```
（仅校验第一个 `## ` 前的正文；本仓库标准稿无 `## `，故整文件校验。命中 `exit 1`。）
