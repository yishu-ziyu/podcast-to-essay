# 0009 段落映射改为模型在每段开头标逐字稿段号

- 日期：2026-09-25
- 状态：采用

## 背景
核对视图要把文章的自然段对到分段稿。旧做法让模型在文末输出 `<<<MAP>>>` 秒区间数组，程序按条数对齐：多写或漏写一条整篇作废，条数碰巧等于行数时按行合并、可能错配。逐字稿每 3 分钟才有一个时间戳，模型给的秒数大多是插值编的。

## 决定
提示词把逐字稿每一块标成【段1】【段2】…，要求每个自然段开头写 `{{N}}` 或 `{{N-M}}`。程序逐段读取标记、换算成该块的起止秒数存进 `paraMap`，保存前删掉标记。存储格式和前端都不变。同时把模型偶尔用单换行分隔的段落拆开（`normalizeArticle`），否则整节会被当成一段。

用真实模型在 3 份真实逐字稿上对比（打分：与每段字符二元组重合最多的块是否落在模型给的区间里）：

| 逐字稿 | 旧：段落 / 覆盖 / 命中 | 新：段落 / 覆盖 / 命中 |
|---|---|---|
| 腾讯阿里 AI 办公（5 块） | 3 / 100% / 100%（跨度 2 块）；另一次 12 / 100% / 67% | 21 / 100% / 95%（跨度 1.1） |
| 课代表立正（5 块） | 6 / 0%（映射作废） | 12 / 100% / 100% |
| 翁家翌访谈（41 块） | 14 / 100% / 43% | 18 / 100% / 78%（相邻块算上 89%） |

## 放弃的选项
- 继续用秒数组，提示词里强调条数：不解决「一条错、整篇废」，也不解决秒数是编的。
- 整理完再单独调一次模型做映射：多花一次额度和时间。

## 后果
映射精度就是一块（约 3 分钟），这也是逐字稿本身的最细粒度。旧文章的 `paraMap` 格式不变，继续可用。
