# 0005 产品名改为「誊清」

- 日期：2026-09-25（提交 `4ef9aea`）
- 状态：采用

## 背景
「录成文」的「录」指录音和转写，但产品不录音，价值也不在转写，而在把口语整理成可读、可核对的文章；三字动词短语像一个按钮。

## 决定
「誊清」：把潦草的草稿抄成干净的定稿，与「初稿 → 文章、原稿留存备查」一致。

## 放弃的选项
- 成稿：一看就懂，但太常见，搜索和商标占不住。
- 纸声、落字：有意境，但不说明用途或有歧义。

## 后果
- 「誊」字部分用户不会读。
- 线上地址 `lcw.yishuziyu.cn` 仍是旧名缩写，暂不改。
- 商标（第 9、42 类）未查，见 [backlog](../backlog.md)。tengqing.com / .cn 已被注册。
