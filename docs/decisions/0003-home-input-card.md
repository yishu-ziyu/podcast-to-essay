# 0003 首页以输入卡为主角，下接最近文章

- 日期：2026-09-25（提交 `cb3fedb`）
- 状态：采用

## 背景
旧首页左边是标语和三步说明，右边是表单：内容只占工作区 24%，同一句话讲 2 遍，主按钮默认置灰，已有文章藏在菜单后面。用户评价「太呆太傻」。

## 决定
居中一句标题 + 一张大输入卡（粘贴链接和拖入文件都在卡里完成）+ 一行步骤说明；下方「最近」三张文章卡（标题、开头摘录、时长或日期）。参照设计标本 `laper#compose`。

## 放弃的选项
- 首页即书房（文章列表为主，顶部细输入栏）：对新用户不友好。
- 三步做成会动的产品卡（参照 minifolio）：适合宣传，对老用户用处小。

## 后果
首页同时服务新老用户；文章多了以后「最近」只显示 3 篇，其余在资料库。
