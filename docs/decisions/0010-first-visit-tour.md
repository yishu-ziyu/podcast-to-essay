# 0010 首次进入巡览 + 第一次读文章的核对提示

- 日期：2026-09-25
- 状态：采用（本地已实现，待部署）

## 背景
公网站点以游客为主，第一次来的人不知道：输入框能直接粘整段分享口令、左上角的两道横线是资料库、转录和整理不会自动开始、文章可以对照原稿核对。步骤卡片上已经写了转录与整理怎么进行，缺的是这几处入口和核对功能的说明。

## 决定
参照 OpenMausBot 的引导（Apache-2.0，[源码](https://github.com/milind-soni/OpenMausBot)），自己实现一份：

- 首页巡览 3 步加收尾：链接输入框 → 选择本地文件 → 资料库按钮 → 「转录和整理都等你点了才开始」。聚光层压暗全窗、只留出目标，步骤之间镂空和提示卡滑动过去；点被照亮的控件本身也算下一步；「跳过」和 Esc 结束。
- 第一次读到文章时，指向「核对」提示一次。巡览没结束时不出现，两处聚光不叠加。
- 目标元素用 `data-tour` 属性找，不依赖 class 名。
- 进度是看过的 id 列表，存在浏览器 `localStorage`（游客没有账号）；资料库底部「重新看引导」只清巡览的进度。

## 放弃的选项
- 为「开始转录」「整理成文章」也加场景提示：卡片文案已经说明，重复。
- 欢迎弹窗、功能短片：誊清只有三步，首页标题和输入卡已经讲清楚是干什么的。
- 进度存服务端：游客没有身份，所有者也只有一人，本地存储足够。

## 后果
换浏览器或无痕窗口会再看一次巡览。以后给界面加新入口时，给目标加 `data-tour`，在 `web/src/onboarding.ts` 里加一步即可。
